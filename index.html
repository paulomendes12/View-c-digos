Instalação como aplicativo

Instale o SiteView para continuar

O SiteView foi projetado para funcionar como um aplicativo web instalado. Isso permite uma experiência mais estável, com armazenamento local e recursos de PWA sem depender de uma aba comum do navegador.

✓
Seguro e localO SiteView não envia os arquivos do projeto para um servidor. A leitura acontece no navegador.
✓
Sem vírus incorporadoEste aplicativo não inclui intencionalmente vírus, malware ou mecanismos de envio automático de arquivos. Ainda assim, arquivos de terceiros carregados por você podem conter código próprio.
✓
Por que instalar?A instalação permite que o navegador reconheça o SiteView como aplicativo e habilite o modo PWA, melhorando a inicialização e a experiência de uso.
✓
Requisito técnicoPara a instalação funcionar, o SiteView precisa ser hospedado em HTTPS ou em localhost. Abrir o HTML diretamente como file:// não permite registrar o Service Worker.
A instalação usa o mecanismo oficial de PWA do navegador quando disponível.
